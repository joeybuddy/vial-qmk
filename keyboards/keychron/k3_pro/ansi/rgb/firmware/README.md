# K3 Pro (ANSI RGB) Firmware

This directory contains pre-built firmware files for the Keychron K3 Pro (ANSI RGB version).

## Firmware Files

Built firmware (`.bin` files) will be automatically generated by the GitHub Actions CI/CD pipeline and stored here.

## Manual Building

To build the firmware yourself:

```bash
# Build Vial keymap
make keychron/k3_pro/ansi/rgb:vial

# Build default keymap
make keychron/k3_pro/ansi/rgb:default
```

Firmware will be generated in the `.build/` directory.

## Flashing

1. Put your keyboard into bootloader mode:
   - Press and hold `Fn + Esc` while plugging in the cable, OR
   - Press the reset button on the back of the keyboard

2. Flash using QMK Toolbox or command line:
   ```bash
   qmk flash -kb keychron/k3_pro/ansi/rgb -km vial
   ```

## Features

- 84-key low-profile layout
- RGB matrix lighting
- Wireless Bluetooth support (3 device multi-host pairing)
- USB-C wired connection
- Vial support for easy keymap customization
- Battery management
- Custom keycodes for Bluetooth host switching (BT_HST1-3) and battery level (BAT_LVL)

## Notes

- Due to EEPROM constraints, VIALRGB is disabled (RGB still works, just not per-key configurable in Vial)
- 2 layers available by default
- Both cable and Bluetooth connections work fully
